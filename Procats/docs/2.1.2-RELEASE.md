# Procats 2.1.2

Card editing and deletion are now available in every Knowledge Collection, including custom collections and search results. Previously, the card menu was only visible under All cards.

- Open the three-dot button on any card to edit its content or delete it.
- On desktop, right-clicking a card opens the same menu.
- Deletion requires confirmation and removes the card from all its collections.
- Existing records, collection memberships, sync behavior and conflict protections are unchanged.
- Touchscreen card menu buttons have a 44-pixel target.

Android phone version code: 40. Wear OS companion build code: 41. No Wear OS behavior changes.
