# Procats 2.0.0

## Release highlights

- First-run sign-in, account creation and local guest mode are available directly from the account screen.
- The first-run privacy step and in-app privacy links were removed. The existing policy URL is still available for older installations. Account deletion is available from the sign-in screen and settings.
- The interface has 20 language choices. New packs translate the account screen, core navigation and common actions. Remaining copy uses English. Arabic is displayed right to left.
- The 3D progress and Knowledge Treasury features are retired. Legacy archive data is not part of routine synchronization. Existing encrypted backups and full account deletion still handle those records.

## Build and update

- **Web:** Use Node.js 22 or newer, then run `npm ci`, `npm test`, and `npm run build` in the Procats folder. A public checkout builds with example Firebase settings. Use your own project configuration and authenticated Firestore rules to enable live accounts.
- **Android and Wear OS:** Use JDK 21 and Android SDK 36, build the web client, then run `npx cap sync android`. The personal variants use `com.procats.study.personal`, with phone version code 34 and watch version code 35. Use the same signing certificate when updating an existing installation.
- **Windows:** Install dependencies in the Windows folder, copy the web build into a fresh `Windows/www` folder, and run `npm test` and `npm run dist`. The x64 installer and portable executable use the same web build. Both are unsigned.

Keep the signing key and encrypted personal backups outside the public repository.
