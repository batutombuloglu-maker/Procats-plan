# Procats 1.7.7

Removed the 3D progress interface, home sticky note and Knowledge Treasury navigation/assets. The original heatmap remains. Existing home-note text is displayed by Quick Notes without deleting or rewriting it. Knowledge storage, account deletion, merge validation and encrypted backup compatibility remain to protect prior records.

The stopwatch uses the same system font and weight as the real clock. Fixed tabular numeric fields repaint independently; centiseconds do not recenter minutes and seconds. Minutes can grow beyond two digits without truncation. Timing, persisted state and alarms retain their existing model.

The task view uses a transparent scrollbar track and a theme-colored thin thumb, with the appropriate native color scheme. Extra padding and a soft edge separate the fixed week strip from the scrolling content. Task layout and calendar selection are otherwise unchanged.

The personal phone/watch package codes are 32/33, both version 1.7.7. Android signing identity is unchanged. No cloud user-data deletion, live Firebase deployment or Play Store upload was performed.
