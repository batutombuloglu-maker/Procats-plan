# Procats 1.7.5 — Add data

## Behavior

Data Vault offers Download data, Restore backup, and Add data. Restore keeps its existing replacement behavior. Add data appends only collections present in a selected file, without deleting or editing existing records. A preview lists additions and skipped matches per section before confirmation. Appearance settings, running timers, navigation selections and focus-history ledgers are not imported by this operation.

Supported collections: `procats_folders`, `yks_v3_days`, `yks_v3_tasks`, `yks_v5_notes`, `yks_v7_bookmarks`, `yks_v8_archives`, `procats_obs_folders`, `procats_obs_notes`, `procats_reminders`, `procats_exams_v1`, `procats_lists_v1`, `procats_knowledge_v1`.

The planner clones incoming records, validates their existing schemas and limits, assigns new IDs, and remaps parent/day/folder links, nested list ordering and knowledge relationships. Matching knowledge content retains the existing card and its review progress. Knowledge duplicates compare format, normalized question, answer and image; matching ignores review metadata, categories, tags and sources. Cosmetic quick-note positioning and progress are also ignored during duplicate matching. Text case and poem line breaks remain significant.

The preview guards the selected collections and their parent dependencies. If those change before confirmation, the user must select the file again. A single account-scoped durable journal write completes before new records are visible. A failed write exposes no partial addition. Sync uses the existing account adapters and conflict handling; cloud delivery still requires network access and the configured Firebase rules.

## Data-pack format

```json
{
  "format": "procats-data-pack",
  "version": 1,
  "title": "My new records",
  "data": {
    "yks_v5_notes": [{ "id": 1, "text": "A new note" }]
  }
}
```

`data` contains only the sections being added, using complete valid records in the current Procats schema. Existing unencrypted Procats backup envelopes and encrypted backups unlocked locally can also be selected. This is not an arbitrary-JSON or CSV importer. Knowledge images must satisfy the existing supported raster-data-URL validation; links to remote images are not fetched.

For a knowledge-only pack, use `procats_knowledge_v1`. The exact card model is defined by `ProcatsKnowledgeCore.make()` and validated by `.check()` in `public/knowledge-core.js`. Examples in `tests/data-add.test.mjs` cover valid cards and references. Omit all other collections to leave them untouched. A related-card reference must exist in the incoming section or the current archive. File limit: 12 MB; existing section and record limits still apply, including 2,000 knowledge cards / 2,000,000 bytes, 750,000 bytes for lists, and the shared main-data limit.

## Display and distribution

Home stopwatch digits now use a monospace font and no letter spacing so changing seconds cannot shift hours and minutes. The compact knowledge-card layout, review intervals, discovery behavior and remaining application sections are unchanged.

Personal Android package: `com.procats.study.personal`, version 1.7.5, phone code 26 and watch code 27. Update existing personal installations in place with the same original signing certificate. The store package is separate. Windows provides installer and portable EXEs without a publisher signing certificate. Firebase Hosting updates only the web client; install new APK/EXE packages for their bundled interfaces.

Export an independent encrypted Data Vault backup before updating. Source code is not a backup of personal records. Keep the signing key and backup password separately. No country/capital content pack, Play Store upload or live Firebase deployment is included in this release task.
