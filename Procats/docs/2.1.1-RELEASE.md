# Procats 2.1.1

## Knowledge Collection

- Right-click a custom collection tab to rename or delete it. The three-dot button offers the same actions on touchscreens and with a keyboard.
- Renaming a collection updates its name on every assigned card. Deleting a collection keeps its cards in their other collections. Cards with no other memberships move to General Knowledge.
- Words, Concepts, and General Knowledge remain the built-in collections. All cards still shows each card once.
- The colored dots on card labels are more prominent across themes.

## Import the sample pack

1. Open **Data Vault → Add data**.
2. Select `Procats-Bilgi-Koleksiyonu-Ornekler.json` from the release's `08-Ornek-Veri` folder.
3. Check the import preview and confirm. The pack contains ten cards and the custom collection **Sınavda çıkanlar**. **Mahir** belongs to both Words and that collection.

Additive import keeps existing records and skips identical entries. Importing the pack again can recreate a sample collection after you rename or delete it.

## Build and update

- **Web**. Use Node.js 22 or newer. Run `npm ci`, `npm test`, and `npm run build` in `Procats`. A public checkout builds with example Firebase settings. Use your own project configuration and the included Firestore rules to enable live accounts. For an existing 2.1.0 deployment, publish the new web build to Firebase Hosting.
- **Android and Wear OS**. Use JDK 21 and Android SDK 36. Build the web client, then run `npx cap sync android`. The personal variants use `com.procats.study.personal`. The phone version code is 38 and the watch version code is 39. Use the same signing certificate when updating an existing personal installation.
- **Windows**. Install dependencies in `Windows` and copy the web build to a fresh `Windows/www` folder. Run `npm test` and `npm run dist` there. The x64 installer and portable executable use the same web build.

Keep the signing key and encrypted personal backups outside the public repository.
