# Procats 1.7.6

The Knowledge Treasury keeps compact, paginated cards, with a dedicated text wrapper to prevent title clipping and contain-fit raster thumbnails. Map cards display a short country label and flag rather than the whole question in the archive. Question text remains intact in storage and in study. Study mode reduces header clutter. Country geometry is drawn as SVG in a theme-aware panel, with optional closer/enlarged views; no bitmap is enlarged to simulate quality.

## Geography and imports

Stable reserved tags of the form `@map/world-2026/CM` reference bundled atlas content without expanding the card schema or the 2 MB archive/2,000-card limits. User-facing tag lists hide reserved references; editing preserves them until a map is explicitly removed or replaced by an uploaded raster. Older clients can still read question/answer text, but cannot draw the new maps. Install the new client on all used devices.

The existing `Veri ekle` action also accepts `procats-knowledge-refresh`, version 1, with `items: [{previous, card}]`. A full content preimage matches the supplied old card after IDs have been remapped. A replacement retains the existing ID, creation time, relationships and review record. User-edited matching content is skipped and counted as protected. Missing countries can be appended. The preview reports additions and replacements separately. Reconfirmation guards the entire knowledge snapshot. One durable journal commit publishes all changes; failed writes or stale previews expose no partial update. Ordinary packs still append without replacing existing records.

Random discovery uses an account-scoped local shuffle bag across sessions. Only displayed cards consume the bag. No card repeats within its filtered pool until that pool has been exhausted; one-card pools necessarily repeat in later rounds. Forgotten discovery cards are not requeued. Scheduled review remains independent. Capitals have a dedicated discovery scope and continent chips.

Population/surface-area observations include source years. English capital names are shown with the Turkish answer. Metadata stores a readable plain-text explanation as well as atlas facts, keeping independent exports useful. User-edited explanations render verbatim. Country outlines do not establish disputed borders or recognition status.

## Home and timers

A single post-it is stored as `homePinned: true` in the existing quick-note collection, so it participates in normal account sync and encrypted backups. It is hidden from the ordinary quick-note grid. Edits use a preimage check; a changed remote note preserves the local draft rather than overwriting it. A short autosave delay is backed by an immediate account-scoped local recovery draft. The visibility preference hides the UI only.

Home progress can show the original heatmap or an event-driven WebGL 3D scene derived from the exact same activity totals. Each completed task contributes a step, with brightness using the heatmap thresholds. Only a bounded camera window is drawn. There is no idle render loop; the short transition respects reduced motion, and SVG provides a fallback where WebGL is unavailable. This is a visual setting and does not modify activity history.

The exam clock can enter full-screen presentation and exit via its button or Escape. Unsupported fullscreen APIs fall back to an app-filling view. Countdown/alarm state remains independent. Thirty-two new thoughts include original reflections and labelled short adaptations, with a source list below. Stable normalized text keys prevent the same thought from being selected again for 15 local calendar days. Existing old builds kept only the current quote date, so unknown pre-upgrade history cannot be reconstructed.

## Performance and safety

Map metadata is small at startup; geometry loads only when the corresponding continent is opened and is bundled for offline use. The 197-card archive shrank from 1,625,744 to 154,540 bytes. A local median review-update microbenchmark improved from roughly 73 ms to 21 ms; this is not a guarantee for every device. Unchanged knowledge storage is no longer repeatedly parsed/validated on unrelated status events. Cached serialized state avoids repeatedly serializing the entire archive to determine pending status. Hidden real-time clock labels no longer trigger text/layout work.

No live user data was edited for tests. No live Firebase deployment, subscription, AI integration or Play Store package was created. User data, server credentials and signing keys are excluded from public source. Keep an independent encrypted backup; indefinite retention and every hardware configuration cannot be guaranteed.
