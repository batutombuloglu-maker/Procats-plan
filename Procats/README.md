# Procats

Procats 2.1.2 is a study planner for the web, Android, Wear OS, and Windows. Its shared workspace includes calendar tasks, practice exams, notes, checklists, timers, resources, and a Knowledge Collection.

See [the 2.1.2 release notes](docs/2.1.2-RELEASE.md) for collection management, importing sample cards, and platform build instructions. [Verification notes](docs/TEST-SONUCLARI.md) describe the release checks.
