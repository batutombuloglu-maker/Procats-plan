# Procats

Procats 2.0.0 is a study planner for the web, Android, Wear OS, and Windows. Its shared workspace includes calendar tasks, practice exams, notes, checklists, timers, and resources.

See [the 2.0.0 release notes](docs/2.0.0-RELEASE.md) for setup and platform build instructions. [Verification notes](docs/TEST-SONUCLARI.md) summarize the release checks.
