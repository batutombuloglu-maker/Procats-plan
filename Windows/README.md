# Procats for Windows — 2.1.0

An isolated Electron shell serving the bundled Procats client. Use Node.js 22+, run `npm ci`, copy the completed sibling web build to `www/`, then `npm test` and `npm run dist`. Output includes installer and portable x64 EXEs. Existing app data is retained during an in-place update; independent encrypted backups are recommended. The EXEs are not publisher-signed. No signing credentials or personal data belong in source control.
