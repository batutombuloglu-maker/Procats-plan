# Procats Windows 1.7.3

Node.js 22+ ile npm ci, npm test, npm run dist. www klasörü 1.7.3 web derlemesidir. Windows 10/11 x64 için Electron kabuğudur; kayıtların mevcut profili korunur. Özel sertifika yoktur. Bilgi Hazinesi için Firebase kuralları güncellenmeli. Web kaynaklarını değiştirdiğinde Procats projesinde npm run build çalıştırıp güncel www içeriğini buraya kopyala ve yeniden derle.
